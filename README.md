# RetortAI 🤖🔥

RetortAI is a modern AI-powered roast chatbot designed to deliver responses in multiple personalities such as Friendly, Savage, Dark Humor, Gen-Z, Corporate, and Random.

## 🚀 Vision

Build a fast, shareable, and professional AI chatbot that anyone can use through a browser.

## 🛠️ Tech Stack (Planned)

- React
- Tailwind CSS
- FastAPI
- Groq API
- Git & GitHub
